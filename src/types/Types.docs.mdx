# TypeScript Types Reference (`src/types/`)

`@vicacha-devs/astro-tiptap-blocks` exports strict TypeScript definitions for every Tiptap AST node, inline mark, Strapi relation descriptor, theme slot, and component prop interface.

---

## 1. Document & Block AST Types (`src/types/tiptap.ts`)

### `TiptapContentInput` & `TiptapDocNode`

```ts
export type TiptapContentInput =
  | TiptapDocNode
  | Array<TiptapBlockNode>
  | string
  | ReadonlyArray<string>
  | null
  | undefined;

export type TiptapDocNode = {
  type: "doc";
  content: Array<TiptapBlockNode>;
};

export type TiptapParserOptions = {
  allowedIframeDomains?: ReadonlyArray<string>;
  resolveInternalLink?: TiptapInternalLinkResolver;
};
```

## 2. Inline Nodes & Marks (`src/types/tiptap-inline.ts`)

- **`TiptapTextNode`**: `{ type: "text"; text: string; marks?: Array<TiptapMark> }`
- **`TiptapHardBreakNode`**: `{ type: "hardBreak" }`
- **`TiptapLinkerNode`**: `{ type: "linker"; attrs: { collectionName?: string | null; documentId?: string | null; label?: string | null; href?: string | null; status?: string | null } }`
- **`TiptapMathematicsNode`**: `{ type: "mathematics"; attrs: { latex: string; displayMode?: "inline" | "block" | boolean | null } }`

| Mark `type` | Attributes Type | Rendered Element |
| :--- | :--- | :--- |
| `"bold"` / `"italic"` / `"underline"` / `"strike"` / `"code"` / `"subscript"` / `"superscript"` | — | `<strong>`, `<em>`, `<u>`, `<s>`, `<code>`, `<sub>`, `<sup>` |
| `"link"` | `TiptapLinkMarkAttrs` (`href`, `target`, `rel`, `title`, `class`) | `<a>` |
| `"highlight"` | `TiptapHighlightMarkAttrs` (`color`) | `<mark>` |
| `"textStyle"` | `TiptapTextStyleMarkAttrs` (`color`, `fontFamily`, `fontSize`, `lineHeight`) | `<span style="...">` |
| `"abbr"` | `TiptapAbbrMarkAttrs` (`title`) | `<abbr title="...">` |
| `"language"` | `TiptapLanguageMarkAttrs` (`lang`, `dir`) | `<span lang="..." dir="...">` |
